# Деплой SpeakEasy на Vercel

Проект работает на Next.js и Node.js. Регистрация по логину и паролю,
Groq, словарь, тесты, магазин и прогресс больше не зависят от ChatGPT или Cloudflare.
Облачная база — Turso (libSQL/SQLite); локально используется файл в `.data/`.

## 1. Подключить базу

В проекте Vercel откройте **Storage / Marketplace**, выберите
[Turso](https://vercel.com/marketplace/tursocloud/database), создайте базу
и подключите её к проекту. Интеграция добавляет `TURSO_DATABASE_URL`
и `TURSO_AUTH_TOKEN`. Либо создайте базу в Turso самостоятельно и добавьте
её URL (`libsql://…`) и токен в **Settings → Environment Variables**.

Для Production используйте рабочую базу. Для Preview подключайте отдельную
тестовую базу: каждая сборка автоматически применяет миграции к указанной базе.
Не выдавайте доступ к рабочей базе непроверенным веткам и внешним PR.

## 2. Настройки импорта GitHub 

Если в репозитории лежит папка `english-pwa`, укажите её в **Root Directory**.
Если содержимое этой папки уже в корне репозитория, оставьте корень.

| Настройка | Значение |
| --- | --- |
| Framework Preset | Next.js |
| Build Command | `npm run vercel-build` |
| Output Directory | По умолчанию Next.js; не `dist` |
| Install Command | `npm ci` |
| Node.js | 24.x |

`vercel.json` уже содержит настройки сборки. В Environment Variables должны быть:

| Переменная | Значение |
| --- | --- |
| `TURSO_DATABASE_URL` | URL облачной базы, `libsql://…` |
| `TURSO_AUTH_TOKEN` | Токен этой базы с доступом к записи |
| `GROQ_API_KEY` | Ваш существующий ключ Groq |
| `GROQ_MODEL` | Необязательно; текущая модель по умолчанию указана в `.env.example` |

Ни одна из этих переменных не должна иметь префикс `NEXT_PUBLIC_`.
Не загружайте `.env.local`, `.dev.vars`, `.data`, `node_modules` или `.next` в GitHub.
После добавления/изменения переменных сделайте **Redeploy**.

## 3. Проверка после деплоя

Создайте аккаунт, пройдите тест, добавьте свою тему и слово в словарь.
Выйдите и войдите снова; проверьте сохранение данных. Разрешите микрофон
и проверьте голосовой разговор на HTTPS-адресе Vercel. Для Orpheus условия
модели должны быть приняты в том аккаунте Groq, которому принадлежит ключ.

## Локальный запуск

В папке проекта:

```powershell
npm ci
Copy-Item .env.example .env.local
# Вставьте GROQ_API_KEY в .env.local. Не перезаписывайте уже заполненный файл.
npm run dev
```

Адрес: http://127.0.0.1:5173. Таблицы создаются автоматически при запуске.
Для проверки production-сборки: `npm run vercel-build`, затем `npm start`.

## Миграции и существующие данные

Миграции в `drizzle/` применяются в транзакциях и записываются в журнал
`_speakeasy_migrations`. Повторная сборка не удаляет пользователей и прогресс.
Уже применённые SQL-файлы не редактируйте; создавайте новые через `npm run db:generate`.
Перед изменением схемы рабочей базы сохраняйте резервную копию.

Новая Turso-база изначально пустая. Данные прежней Cloudflare D1 и локальные
данные не копируются автоматически. Если требуется сохранить прежние аккаунты,
нужен отдельный экспорт D1 и согласованный импорт в Turso; старую базу сохраняйте.
Импорт профилей по заголовкам ChatGPT на новом хостинге отключён.

База и секреты должны быть доступны на этапе сборки и во время работы функций.
Отсутствующие облачные настройки останавливают сборку с ошибкой вместо создания
временной базы в файловой системе Vercel.
